# 隐私与数据说明

## 本机处理

文档解析、图片文字识别、脱敏预览、录音转写和导出在本机执行。本地 HTTP 服务限制为本机访问。源码目录中不附带使用者 API Key、真实材料或语音模型。

源码版文件副本和会话记录位于项目目录的 `uploads/`；Mac 安装版使用用户“资源库/Application Support/TrainingOnePager”。本次运行数据放在单独运行目录。记录包含文档版本、脱敏选择及确认信息等。下载的语音模型保存在相应数据目录的 `models/`，或使用配置的模型路径。

## 何时联网

| 操作 | 网络目标及内容 |
| --- | --- |
| 安装 Python 依赖或外部工具 | 所配置的软件源，下载程序文件 |
| 下载语音模型 | 模型托管站点，下载模型文件 |
| 更新模型列表 | 所选服务平台；请求可能携带该平台的 API Key |
| 测试模型连接 | 所选模型服务，发送密钥、模型设置及简短测试请求 |
| 生成、重生成或问答 | 所选模型服务，发送确认脱敏后的相关文字、问题及写作要求 |
| 本地规则生成、本地编辑、录音转写 | 对应处理不依赖远程模型调用 |

图片文件、图片遮挡坐标和原始录音不会由现有生成流程发送给模型；图片识别出的文字在核对、确认脱敏后可以成为生成输入。自动脱敏不保证识别所有秘密，请在确认前自行核对。

生成服务对收到的数据如何保存、使用或计费，取决于使用者选择的平台及其服务条款。远程请求取消后，对方可能已经收到内容并继续计费。

## 密钥与浏览器保存

页面中的 API Key 只供当前页面连接使用，不写入浏览器持久存储。刷新后需重新输入；但服务端也支持通过环境变量配置密钥，页面清除密钥不会删除进程环境变量。

浏览器可保存上次验证的模型 ID 和使用者主动保存的常用词语。常用词语本身也可能敏感；清除浏览器站点数据可以删除这些保存项。

## 清理边界

清空或成功替换材料会删除关联副本；解析失败保留上一份材料。正常退出清理本次运行数据，异常退出残留在下一次启动时处理。下载模型、使用者原文件、自行导出的文件及浏览器保存项不随材料清空一起删除。旧版本历史文件需单独核对。

这些是应用层删除行为，不等于磁盘取证意义上的安全擦除；系统备份或同步软件可能另有副本。请按自己的资料管理要求选择存放位置和模型服务。
