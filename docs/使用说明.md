# 使用说明

## 1. 上传并核对解析结果

上传材料，点击本地解析。查看文字、页码、顺序和图片，确认解析结果后进入脱敏。主材料支持常见文档、表格和录音格式。

旧版 DOC/PPT 需 LibreOffice 转换。表格主要读取已保存的单元格结果，不复刻完整格式或图表。扫描 PDF 和图片识别可能遗漏；解析结果 Word 是内容重排，不是原版式无损转换。

普通材料默认最大 1024 MB；录音默认最大 200 MB、120 分钟。体积和时长越大，处理越慢；这些限制可通过环境变量调整。

## 2. 检查并确认脱敏

黄色文字表示将被替换的内容。单击切换全文相同内容，双击切换当前位置；选中文字可补充遗漏项。图片可拖动添加遮挡框，并预览遮挡效果。

自动识别只能作为检查辅助。请自行核对姓名、联系方式、证件、账号、机构及其他不宜外发的内容，确认后再生成。解析结果 Word 可能含原始信息；脱敏版 Word 使用已经确认的替换和遮挡。

## 3. 选择生成方式

“本地规则”无需密钥，页面明确选择本地规则或尚未连接模型时，不调用远程生成服务。它适合体验和制作初稿，不能保证理解复杂语义。

使用大模型时，选择服务平台和型号，填写本人有权使用的 API Key，点击“测试并使用”。切换型号或思考设置后重新测试。测试本身会向所选服务发送一条简短请求；能否使用取决于账号权限和服务状态。

页面支持预设服务及兼容接口。部分平台不能使用生成密钥查询模型列表；列表更新失败时可按平台提供的信息手动填写模型 ID。页面内置候选不代表账号一定具有权限。

## 4. 生成、核对和导出

填写身份、重点主题、字数及表达要求，选择文字或框架图版式。“必须逐字保留”填写原文确有的短句。

长材料分批提炼，显示阶段和耗时。生成期间可以取消；已发送给模型的请求可能继续处理和计费。再次生成会从头开始。

点击出处核对脱敏原文，再编辑标题、结构和要点。生成后可根据主材料问答，选择将有出处的回答加入成稿。人工编辑与重新排版不调用模型。

导出前检查字数和 A4 单页版面。来源可在工作台核对，导出文件不提供同样的在线点击能力。Word 中的框架图以图片嵌入。

## 5. 录音使用

Mac 安装版已包含语音模型，安装后即可识别录音。源码版需自行安装外部工具和模型。安装需要可用磁盘空间；转写在本机完成。

可以填写专业术语提示，校对自动转写文字和说话人标签，按时间回放，再确认进入原有脱敏流程。提示、断句和自动标点均可能不准确。

## 6. 清空与结束

成功替换材料或点击“清空材料”时，工具删除对应本机副本及关联数据；失败会提示重试。原始文件不受影响。

正常结束服务会清理本次运行目录，异常退出残留在下次启动时处理。已下载模型和自行导出的文件仍保留。旧版本历史上传文件需自行核对。

## 常见问题

- 无法启动：检查 Python 版本和依赖安装是否成功，端口是否被其他程序占用。
- 无法生成：先确认解析和脱敏，再检查模型是否测试成功、账号是否有权限；也可选择本地规则体验。
- Word 中文显示异常：确认本机存在可用中文字体。
- 录音不可用：检查 FFmpeg、ffprobe、whisper-cli 和模型文件；源码版本不会自动安装外部程序。

反馈问题时，只提供已去除敏感内容的错误说明和必要环境信息。不要在公开问题页面提交真实材料、API Key、个人信息或完整原始日志。
